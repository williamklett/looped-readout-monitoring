\subsection{Compute and software}\label{app:compute}
Each reported training job requested one GPU allocation, eight CPU cores, and 48 GiB of host memory on a Slurm-managed university cluster. Completed-job records show that 55 of the 81 native arithmetic runs used an NVIDIA A100 MIG 3g.20gb partition, while 26 used an A100 GPU allocation. The twelve historical arithmetic comparisons, five arithmetic continuations, and chess board-family runs used A100 MIG 3g.20gb partitions. The native runs took approximately 20--36 minutes each, the continuations 103--104 minutes, and the chess family runs 56--162 minutes. These are allocated-job elapsed times, including evaluation and integrity checks, not isolated training times or a total development-compute estimate. Failed pilots and model preparation add compute beyond these totals.

The preserved cluster environment, rechecked on October 1, 2026, uses Python 3.12.4, PyTorch 2.8.0+cu128 (CUDA runtime 12.8), Transformers 4.55.4, python-chess 1.11.2, safetensors 0.8.0, and huggingface-hub 0.36.2. This is a dated environment check, not a dependency lock recorded independently for every historical run. The published training requirements match this check; we have not rerun training in a freshly installed environment. CPU analysis was verified with NumPy 2.0.2, Matplotlib 3.9.4, python-chess 1.11.2, and pypdf 6.12.1.

We use \href{https://huggingface.co/ByteDance/Ouro-1.4B}{ByteDance's Ouro-1.4B} model and tokenizer, with recorded revision \texttt{574fa66cb8bf5abdc979642d01cf2b79b16bfab1}. The released model interface retains upstream notices. Board scoring uses Stockfish 11, searched to depth 8; the executable hash is recorded in the package. The model weights, starting adapters, and engine executable are external assets, not included in the analysis archive. The exact adapter hashes are supplied so that substituting different weights cannot be mistaken for an exact reproduction.

\subsection{Anonymous analysis package}\label{app:anonymous-package}
The separate \path{anonymous-reproducibility.zip} contains the analysis and figure scripts, dependency specifications, synthetic boards, frozen predictions, saved evaluations, source code, asset documentation, and a checksum manifest. It excludes author-identifying manuscript sources, Git history, machine-specific identifiers, model weights, and engine binaries. The README gives commands to recompute the reported summaries and figures on a CPU. The extracted archive is checked by running those commands and the metric, evaluation, and schedule tests. This verifies the analysis of saved measurements; independently reproducing training requires the external assets and a documented port of the original cluster configuration. Normalized paths change source-file hashes, so historical execution manifests and archive-content hashes serve different purposes.
